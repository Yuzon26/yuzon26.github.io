## GIT常用指令
*  git status 查看本地库
* git add 文件名 添加到暂存区
* git add . 全部添加到暂存区
* git commit -m "日志信息" （文件名） 提交到本地库
* git push origin (master/创建分支的名字) 上传到远程库

##  新建本地仓库并关联到远程仓库
1. git init  初始化本地仓库
2. git remote add origin https://github.com/Yuzon26/repo.git  添加远程仓库
3. git add .  添加文件并提交
   git commit -m "Initial commit"
4. git push -u origin main  推送到远程仓库(-u 会把 origin/main 设置为默认上游分支，以后直接 git push 就行。)

* #### 若远程仓库无分支
4. git branch  确认本地分支
5. git branch -M main  改名为 main
   git push -u origin main
